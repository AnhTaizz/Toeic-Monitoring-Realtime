## Configuration completion

`application.properties` already mapped `toeic.image.root=${TOEIC_IMAGE_ROOT:image-resources}`, but the normal Windows startup path did not load `TOEIC_IMAGE_ROOT` from `.env` and `.env.example` did not advertise it. This closeout adds the variable to both, documents it beside `TOEIC_AUDIO_ROOT`, and keeps both roots outside the database and packaged JAR.

Expected layout:

```text
TOEIC_AUDIO_ROOT/<examId>/<audioFile>
TOEIC_IMAGE_ROOT/<examId>/<localFile>
```

The server derives paths from trusted configuration plus validated exam/media identifiers. Import requests cannot select a filesystem root.
