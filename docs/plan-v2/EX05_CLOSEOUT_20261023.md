## Filename boundary

The HTTP contract never accepts or exposes `localFile`; clients request `/api/v2/attempts/{attemptId}/images/{mediaId}`. Server-side filenames are intentionally restricted to a portable ASCII allowlist, so spaces and Unicode cannot become URL/path ambiguities. Unicode is supported in user-facing text and metadata, while filesystem names remain private implementation data. This is the controlled resolution of the task card's manual filename-download note rather than widening the endpoint to accept raw filenames.
